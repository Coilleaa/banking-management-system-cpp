# Banking Management System (C++)

A simple console-based banking management system written in C++.

## Features
- Create bank accounts
- Deposit money
- Withdraw money
- Transfer money between accounts
- Search account by ID
- Display account statistics

## Technologies
- C++
- MSVC Compiler
- Visual Studio Code

## How to Run

Compile the program:

cl main.cpp

Run the program:

main.exe
